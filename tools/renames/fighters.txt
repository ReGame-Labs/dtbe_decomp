# src/battle/fighters/: the 24 fighters, run with --overlay game. Each file's class is the character of its
# CHARACTER_* id: createFighter's switch builds fighter NN's class for id NN, and the per-character tamer table
# (CHARACTER_TAMERS) agrees. A class's methods take FighterVtable's slot names (its vtable's entry for that
# slot); the faces table is the one the constructor gives Fighter_setFaceTable. A fighter's own entity classes are
# named <Character><Move><Kind>: the move whose method spawns them, and the kind by what they derive from
# (Projectile, Particle; Hitbox: Entity + Hit + CollisionSphere; Effect: Entity only, it only draws). Their
# methods: entity slots tick/draw/destroy, the Hit vtable's (X_HIT_VTABLE) slot 0x08 `hit`; spawners
# <Character>_spawn<Class>: they only allocate, construct and Fighter_addEntity it.
